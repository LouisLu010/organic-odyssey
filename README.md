# 有机漫游 · Organic Odyssey

面向高中有机合成的闯关游戏。每关必做合成路线，前置推理题可选；配有递进提示、逐步解析、易错点、反应图鉴与学习笔记。

## 本地运行

建议使用 Node.js 22.12+ 或 24+。

```sh
npm install
npm run dev -- --port 5173
```

浏览器打开 `http://localhost:5173`。

```sh
npm run build
npm test
npm run preview -- --port 4173
```

`build` 执行 TypeScript 检查并生成 `dist/`；`test` 运行规则与题库测试并输出覆盖率。

## GitHub Pages 自动部署

仓库的 GitHub Pages 发布来源选择 **GitHub Actions**。推送到 `main` 分支后，[部署工作流](.github/workflows/deploy.yml) 会使用 Node.js 24，依次执行 `npm ci`、`npm test`、`npm run build`，通过检查后发布 `dist/`。也可以在仓库的 Actions 页面手动运行该工作流。

Vite 使用相对资源路径，首页素材跟随 `import.meta.env.BASE_URL`，支持 GitHub Pages 的仓库子路径和本地预览。页面路由使用 URL hash，刷新关卡链接无需配置服务器回退。实际访问地址以成功的部署任务输出为准。

## 路线与绘图

- 以真实键线式流程图展示底物、中间体和目标物，箭头标注试剂与反应条件。
- 点击待补全节点，在简化分子画板中直接画键、添加原子与环。绘图工具基于 OpenChemLib，保存前检查结构是否为空及基本化合价。
- SmilesDrawer 根据结构数据渲染分子，示意图与绘图均为可操作的应用界面。
- 笔记、作答与学习进度保存在当前浏览器的 `localStorage`，存储键为 `organic-odyssey.progress.v1`。笔记支持导出为 Markdown。
- 游戏运行不依赖 AI 服务，也不需要配置 API 密钥。

## 判题范围

规则判题验证给定路线各步的连接关系、官能团和键级，以及预设的关键试剂和条件。结构比对不以分子式相同代替连接方式相同；文字条件按已设定的等效表达匹配。

本游戏不考查立体异构：忽略手性中心的 R/S 构型、对映体差异及双键 E/Z（顺反）差异，无须绘制楔形键或指定双键构型。位置异构、碳骨架、官能团与键级仍需正确。参考图和参考 SMILES 可保留原卷的立体信息，仅供科学说明，不作为通关条件。

这属于关键点评估，不是任意合成路线的化学证明。未识别结构或其他合理替代路线，需要结合解析与原题进行人工复核。获得高分也不代表实际实验中没有副反应或工艺限制。
